# Final response format — mandatory

All responses must be succinct, clear, and understandable to someone without
specialized knowledge of the subject.

Explain technical terms when their meaning is not obvious. Never use an acronym
without first stating or explaining what it means, unless the user already used
or clearly knows that acronym.

Avoid unnecessary repetition, background information, and verbosity.

For substantial explanations, analyses, plans, reviews, or completed work, use:

**Detailed explanations:**
<concise but sufficiently detailed explanation>

**Succint explanations:**
<standalone summary containing the important conclusion and proposed solution>

The succinct section must make sense without reading the detailed section.

When code or repository work occurred, additionally end with:

Branch: <branch>
Commits: <commits made, or None>
Pushed: <Yes or No>

For simple questions, confirmations, clarifications, or very short answers,
do not add Detailed/Succint sections unnecessarily.

Never repeat or regenerate an otherwise correct response solely to satisfy
this format.
